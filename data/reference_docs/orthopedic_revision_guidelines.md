# Synthetic Orthopedic Revision Coding Guidelines

Revision total knee arthroplasty is represented by CPT 27487 in this demo when both the femoral and tibial components are revised.

Revision total hip arthroplasty is represented by CPT 27134 in this demo when both acetabular and femoral components are revised.

Documentation should identify the joint, components revised, reason for revision, implant details, complications, and whether the procedure was staged.

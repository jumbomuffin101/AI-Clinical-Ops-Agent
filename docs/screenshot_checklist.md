# Screenshot Checklist

Capture these after running the app locally or deploying it.

1. Empty dashboard
   - Fresh page load before submitting an analysis.
   - Shows project header, input panel, empty result sections, and recent analyses area.

2. Example note selected
   - Select a synthetic note from the dropdown.
   - Show the No PHI warning and note text.

3. Ready claim result
   - Run AV fistula, carotid endarterectomy, appendectomy, or diagnostic colonoscopy.
   - Capture claim readiness score, CPT table, and reimbursement estimate.

4. High Risk claim result
   - Run `Bundled chole risk`.
   - Capture the High Risk score and bundling conflict audit warning.

5. CPT evidence table
   - Capture CPT Candidate Table and Evidence Used section together if possible.
   - Show source document names and snippets.

6. Audit warning section
   - Run `Hernia missing side`, `Angiogram incomplete`, or `Bundled chole risk`.
   - Capture severity, category, related code, and recommendation.

7. Recent analyses panel
   - Submit at least three example notes.
   - Capture recent analysis titles, top CPT codes, reimbursement, and readiness statuses.

8. JSON export section
   - Capture the Final Report card with Copy JSON and Download JSON buttons.
